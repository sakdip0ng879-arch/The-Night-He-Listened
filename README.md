# What If — ถ้า Liu Bei ฟังคำทัดทานของ Zhao Yun

พงศาวดารจากอีกเอกภพหนึ่ง ค.ศ. 221 – 274 อ่านคู่กับแผนที่ที่เดินไปพร้อมเรื่อง
เลื่อนอ่านทางขวา แผนที่ทางซ้ายเดินตาม กองทัพเดินตามถนนที่มีอยู่จริง ผ่านด่านที่ต้องผ่าน
ข้ามแม่น้ำเฉพาะที่มีท่า และทุกเส้นบอกว่าเป็นของใครยกไปเท่าไหร่

**เอกภพนี้มีจุดแยกจุดเดียว** — ฤดูร้อนปี 221 กลางท้องพระโรงที่ Chengdu ทหารคนหนึ่งคุกเข่าลง
แล้วบอกจักรพรรดิว่าความแค้นของท่านผิดลำดับ และคราวนี้จักรพรรดิฟัง
ทุกอย่างหลังจากนั้นคือผลลูกโซ่ของคืนเดียวนั้น

ทุกฉากมีป้ายกำกับ **จริง · ผสม · แต่ง** กดที่ป้ายเพื่อดูว่าส่วนไหนมีบันทึกรองรับและส่วนไหนเติมเข้าไป
เกณฑ์ตัดสินอยู่ใน `docs/DECISIONS.md` §8

## เปิดยังไง

ดับเบิลคลิก `index.html` ไม่ต้องลงอะไร ไม่ต้องรัน server
(ทั้งโปรเจกต์เป็น HTML/CSS/JS ล้วน ไม่มี build step ไม่มี dependency)

**ลิงก์ตรงถึงฉากไหนก็ได้** — เติม `#` ตามด้วย id ของฉาก เช่น
`index.html#c7-13` (โหมดสองเอกภพ) · `#c10-09` · `#c12-02` (ฉากปิดเล่ม)
· มาด้วยลิงก์แบบนี้จะข้ามหน้าเปิดให้เลย
**`?intro=1`** บังคับให้หน้าเปิดโชว์เสมอ (ใช้ส่งลิงก์ชวนคนดูคำนำ) ·
**`?intro=0`** ปิดหน้าเปิด — `shot.ps1` กับ `check_click` ใช้ตัวนี้
· หรือกดปุ่ม **ⓘ คำนำ** บนแถบเครื่องมือเหนือแผนที่ได้ทุกเมื่อ

เปิดมาจะเริ่มที่ฉากแรกเสมอ ถ้าเคยอ่านค้างไว้จะมีแถบ **"อ่านต่อ"** ให้กดข้างล่าง
· กด **"หน้าเปิด"** ท้ายคอลัมน์เพื่อกลับไปดูคำนำกับทางลัดสามฉากอีกครั้ง

## ต่างจากสองโปรเจกต์ก่อนตรงไหน

| | โปรเจกต์ 1 | โปรเจกต์ 2 | **โปรเจกต์นี้** |
|---|---|---|---|
| จุดแยก | ขงเบ้งเชื่อคำเตือนเรื่อง Ma Su (228) | Guan Yu ฟัง Ma Liang (219) | **Liu Bei ฟัง Zhao Yun (221)** |
| ช่วงเวลา | 228–276 | 219–256 | **221–274 (53 ปี)** |
| ภาษา | อังกฤษ | อังกฤษ | **ไทย** |
| เส้นทางเดินทัพ | เส้นโค้งวาดมือ + กฎ "คด ≥ 3%" | เหมือนกัน + กฎรูปทรง | **กราฟถนน — ประกาศเป็นรายชื่อจุด** |

**สิ่งที่เปลี่ยนใหญ่ที่สุดคือเส้นทางเดินทัพ** สองโปรเจกต์ก่อนวาดเส้นโค้ง SVG ด้วยมือทีละเส้น
แล้วให้ตัวตรวจไล่ดูทีหลังว่าคดพอไหม — ซึ่งตรวจ *รูปร่าง* ไม่ได้ตรวจ *เส้นทาง*
ตอนนี้ถนนเป็นกราฟของจุดกับช่วง และการเดินทัพประกาศเป็นรายชื่อจุด
กฎที่เคยเป็นกฎสี่ชั้นจึงกลายเป็นสิ่งที่ละเมิดไม่ได้ตั้งแต่โครงสร้าง — ดู `docs/DECISIONS.md` §4

## โครงไฟล์

```
index.html          ทั้งหมดอยู่ในหน้าเดียว
css/ js/            engine — เขียนครั้งเดียว แทบไม่แตะอีก
data/               เนื้อหาทั้งหมด แก้ที่นี่ ห้ามแก้ที่โค้ด
  _part1..N.js      ที่มาของฉากทั้งหมด  →  timeline.js (generated — ห้ามแก้มือ)
  roads.js          ★ กราฟถนน — node · edge · การเดินทัพ  →  สร้าง TK.routes ให้ engine
  geo.js            รูปเขตที่วาดมือ  →  geo_fill.js (generated)
tools/              ตัวสร้างและตัวตรวจ
docs/               กฎที่ล็อกแล้ว · บั๊กที่เคยเจอ · รีวิวเนื้อเรื่อง
What_If_Zhao_Yun_Remonstrance.md    ★ ต้นฉบับ = source of truth · ห้ามแก้
```

## เครื่องมือ

```bash
node tools/build_timeline.js     # data/_part*.js  →  data/timeline.js
node tools/build_geo.js          # geo.js + landmask  →  geo_fill.js
node tools/check_routes.js       # ★ กราฟถนน · การเดินทัพ · ขบวนเสบียง
node tools/check_map.js          # เจ้าของเขตเทียบกับที่ฉากบอก + ลูกศรออกจากดินตัวเอง
node tools/check_camera.js       # กล้องกรอบสิ่งที่ฉากชี้จริงไหม
node tools/check_hud.js          # ตัวเลขประชากร/กำลังพล และเลขบนป้ายเทียบกำลังที่มี
node tools/check_fact.js         # ป้ายจริง/แต่ง เทียบกับเกณฑ์
```

`tools/test_roads.html` — เปิดในเบราว์เซอร์เพื่อตรวจตัวสร้างกราฟถนน (ต่อ edge · กลับด้าน path · รอยกระโดด)
`tools/shot.ps1 c1-05` — ถ่ายภาพการเรนเดอร์จริงของฉากที่ระบุ

> ⚠ **เรียก `build_timeline` แบบไม่ตัด output เสมอ** — `| Select-Object -First 1` ทำให้ PowerShell
> หยุด pipeline ก่อนถึงบรรทัดสรุปท้ายสุด แล้วจะนึกว่าผ่านทั้งที่ไฟล์ไม่ได้ถูกเขียน (`BUGS_SEEN` §C1)
