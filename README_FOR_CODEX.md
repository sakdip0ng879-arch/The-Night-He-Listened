## 2 · ระบบพิกัด — ข้อเดียวที่ต้องจำ

**ทุกอย่างในโปรเจกต์นี้ใช้พิกัดเดียว: พิกเซลบน `assets/map.jpg` ขนาด `1650 × 1950`**

- SVG หลักคือ `#tkmap` · `viewBox` เลื่อน/ซูมไปมา แต่หน่วยไม่เคยเปลี่ยน
- ชั้นภาพของคุณต้องเป็น `viewBox="0 0 1650 1950"` ตรง ๆ วางทับได้เลยโดยไม่ต้องแปลงอะไร
- ของที่ต้อง **ขนาดคงที่บนจอ** (หมุด · ความหนาเส้นทาง) โค้ดคูณ `mu = หน่วยแผ่นต่อ 1 พิกเซลจอ` ให้เอง
  — ยกเว้นเส้นที่ใช้ `vector-effect:non-scaling-stroke` ซึ่งเบราว์เซอร์คุมให้ (เช่น `.zline`)

## 4 · ★★ สองเส้นทางโหลด — กับดักที่เคยกัดมาแล้ว

ชั้นภาพของคุณถูกโหลด **สองทาง** และต้องได้ภาพเดียวกัน:

| ทาง | กลไก | อ่านอะไร |
|---|---|---|
| `http://` | `import()` + `fetch()` | `assets/map-art/*.svg` ตรง ๆ |
| `file://` | `<script src>` ธรรมดา | `assets/map-art/map-art-inline.js` (ข้อความ SVG ที่ฝังไว้) |

**`file://` บล็อกทั้ง `import()` และ `fetch()`** (วัดจริงด้วย Chrome headless แล้ว) — ผู้อ่านที่ดับเบิลคลิกจึงต้องพึ่งไฟล์ฝัง

> ⚠ **ทุกครั้งที่คุณส่ง SVG รุ่นใหม่ ต้องรัน:**
> ```bash
> node tools/build_map_inline.js
> ```
> ไม่รัน = คนเปิดผ่านเซิร์ฟเวอร์เห็นรุ่นใหม่ · คนดับเบิลคลิกเห็นรุ่นเก่า **เงียบสนิท ไม่มี error**
> `node tools/check_map_inline.js` จับกรณีนี้ให้ (สร้างใหม่ในหน่วยความจำแล้วเทียบไบต์)

**PNG ไม่ต้องฝัง** — raster โหลดผ่าน `file://` ได้อยู่แล้ว

### 6.2 ตัวตรวจ — **รันให้ครบก่อนส่งงานทุกครั้ง**

```powershell
Get-ChildItem tools/check_*.js | Where-Object { $_.Name -notlike "*OLD*" } | ForEach-Object {
  node $_.FullName | Out-Null
  "{0,-24} {1}" -f $_.Name, $(if ($LASTEXITCODE -eq 0) { "OK" } else { "FAIL" })
}
```
> ⚠ ต้องใช้ `$LASTEXITCODE` **ห้ามใช้ `$?`** — PowerShell 5.1 ตั้ง `$?` เป็น false ได้เมื่อ exe
> เขียนอะไรลง stderr แม้ exit code จะเป็น 0 → ได้ FAIL ปลอม (สคริปต์ข้างบนทดสอบแล้วว่าถูกต้อง)

(บน bash: `for f in tools/check_*.js; do node "$f" >/dev/null 2>&1 && echo "OK  $f" || echo "FAIL $f"; done`)

## 8 · บทเรียนสามข้อที่ทำให้เสียเวลาซ้ำ ๆ

1. **ทุกครั้งที่เปลี่ยนสถาปัตยกรรมของชั้น ต้องกลับไปวัดค่าที่เคยวัดไว้ใหม่ทั้งชุด**
   ตัวอย่าง: ยกเงาเขาขึ้นไปเป็น multiply แล้ว ตาราง "ตั้ง .45 แล้วภูเขาหาย" ก็ล้าสมัยทันที แต่ไม่มีใครกลับไปวัด → ค้างเป็นทางแก้ของปัญหาที่แก้ไปแล้ว
2. **ก่อนเชื่อว่าข้อมูลผิด ให้ถามก่อนว่าไม้บรรทัดวัดถูกเรื่องหรือเปล่า**
   เจอสามครั้งในสองวัน: `measureText` ไม่รู้จัก `letter-spacing` · หน้ากาก `landmask` นับแม่น้ำเป็นน้ำ · เครื่องมือเทียบแม่น้ำสกัดผิดชั้น
3. **การทดลองที่ผลลัพธ์เป็นสองสถานะ ต้องรันซ้ำก่อนสรุป**
   เกือบทิ้งข้อกล่าวหาผิดใส่ไฟล์ที่ไม่ได้ผิด เพราะทดลองรอบเดียวแล้วจด
