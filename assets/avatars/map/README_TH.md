เพิ่มคนในเมืองตาม `data/scene_people.js` สามฉาก: c1-01 จ้าวหยุน/หลิวเป้ยที่เฉิงตู, c1-06 จ้าวหยุนบนเส้นทัพเดิม (หลิวเป้ยและเติ้งจืออยู่ในแถวคนในฉาก), c1-08 จางเฟยบนเส้นม้าเร็วเดิมและหลิวเป้ยที่เฉิงตู แถวคนในฉากกดดูบทบาทได้ คนที่ไม่มี place ไม่ใช่หมุดตำแหน่งบนแผนที่

ตัวเลขใต้รูปและป้ายกำลังพลบนแผนที่ใช้จำนวนเต็มมีจุลภาค เช่น 15,000 / 100,000 พื้นป้ายวัดตามความกว้างจริงและเข้าระบบหลบด้วยขนาดเดียวกัน คำว่า “ถอย” คงเดิม ไม่ได้เพิ่มจำนวนพลที่ฉากไม่ระบุ

- เส้นทางที่ marker ระบุ `who` ใช้ภาพเจ้าของ id นั้นเท่านั้น ปัจจุบันมี 66 รายการใน 54 ฉาก ภาพเคลื่อนตามเส้น/ลำดับคลื่นของ engine เดิม แล้วเปลี่ยนเป็นกรอบรายละเอียดเมื่อเดินทางจบ
- ภาพที่กำลังเดินวางใน SVG `L-people` เหนือไอคอนเมืองเพื่อกันหลังคาบังหน้า ใช้กล้อง/พิกัด/tween เดิม ล้างชั้นนี้พร้อม marker ทุกครั้งที่เปลี่ยนฉากหรือชมปก
- ไม่มี who ยังคงใช้สัญลักษณ์หรือป้ายเดิม ไม่เดาแม่ทัพจากข้อความ และไม่ได้ใส่ตัวละครทั้ง 80 คนพร้อมกันทุกฉาก
- กดรูปเพื่อดูชื่อ ฝ่าย จำนวนคนที่ฉากระบุ และต้นทาง–ปลายทาง กดซ้ำหรือ Escape เพื่อปิด เมื่อเปลี่ยนฉากล้างการเลือกเสมอ
- ข้อความเหตุการณ์ใช้ addCaption/addChip เดิมของ Claude ไม่ใช้กล่องครีมอีก ชื่อเมืองและไฮไลต์อยู่ที่ไอคอนเมืองตามเดิม ข้อมูล timeline เพิ่มเฉพาะ who ที่ขาดสามเส้น เนื้อเรื่อง/เส้นทาง/กำลังพลไม่เปลี่ยน
- กรอบภาพจูนรายคนมาแล้ว ใช้ contain ไม่เพิ่ม CSS zoom หรือเลื่อนขึ้นอีก พู่หมวกสูงทำให้ขนาดใบหน้าแตกต่างเล็กน้อยได้
- ภาพ 256 ใช้กับหมุดและรายละเอียดที่ขยายแล้ว ภาพ 128 ใช้กับรูปเล็กระหว่างเคลื่อนที่ ความโปร่งใสและ hash ตรวจจาก manifest.json ได้
