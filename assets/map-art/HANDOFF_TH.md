# แผนที่รุ่น 03 — ส่งต่อให้ Claude

8 กันยายน 2026 · งานทั้งหมดอยู่ใน `prototypes/codex-2026-09-06` · ไม่แก้ production

## สิ่งที่ส่งมอบ

แผนที่ครอบคลุมกรอบต้นฉบับทั้งแผ่น **1650 × 1950** มีทางน้ำ 95 ช่วง ทะเลสาบ 9 รูป และทะเล/ชายฝั่ง 4 รูป กำแพงเมืองจีนแยก 13 polyline จาก `data/wall.js` ของงานจริง ภูมิประเทศรุ่น 03 ลดความอิ่มสีและความเข้ม พร้อมเพิ่มภูเขาบริบทตะวันตกเหนือเฉิงตูตามตำแหน่งที่เจ้าของยืนยัน

**ส่งต่อได้ในฐานะชั้นภาพศิลปะความเข้มต่ำ** ยังไม่ใช่ภูเขาความละเอียดจริง 2×: ขอ ImageGen 3300×3900 แล้ว แต่ไฟล์ที่ได้จริงคือ **1153×1364** จึงใช้ทางสำรองตาม NOTES_FROM_CLAUDE_TH.md §2 โดยลด saturation เหลือ .5 บีบ contrast และใช้ opacity .65 ไม่ได้ขยายพิกเซลแล้วอ้างว่าละเอียดขึ้น รายละเอียดที่ต้องคมเป็น SVG ได้แก่ น้ำ กำแพง และชั้นข้อมูลเดิมของแอป

## การเสียบเข้าระบบเดิม

ทุกชั้นใช้ `viewBox="0 0 1650 1950"` จุดกำเนิดซ้ายบน ไม่ใช้ TPS ไม่ย้ายหมุด ไม่เปลี่ยนถนน กล้อง timeline หรือปีของสถานที่

ลำดับจากล่างขึ้นบน:

1. `terrain-layer.svg` ซึ่งรวมสีพื้นและภาพภูเขา
2. สีเขต/ผู้ครอบครองจากระบบจริง ให้โปร่งพอเห็นภูมิประเทศ
3. `water.svg` **เลือกแทนชั้นน้ำเดิมหนึ่งชุด** ไม่วาดสองชุดซ้อนกัน
4. กำแพงเดิมของ Claude **หรือ** `wall.svg` เลือกอย่างใดอย่างหนึ่ง
5. ถนน ป้อม/รั้ว/งานก่อสร้าง และข้อมูลฉาก
6. รูปสถานที่ ลูกศร เหตุการณ์ ป้ายชื่อ และ interaction ตามลำดับของ renderer จริง

ฐานใหม่นี้แทนภาพแผ่นพิมพ์เดิมในโหมดที่เปิดใช้: ไม่ควรวางภาพต้นฉบับที่มีหมึกชื่อ/เมืองทับลงมาอีก สำหรับโหมดเทียบต้นฉบับให้สลับทั้งฐานเหมือนหน้าต้นแบบ **ไม่มี mix-blend-mode:multiply กับภาพแผ่นเดิมในรุ่น 03** และไม่ใช้ภาพภูเขาดิบเต็มแผ่นโดยไม่มี mask

**PNG แยกไฟล์ใช้ได้เมื่อ SVG เป็น inline DOM** ถ้าใช้ `<img src="terrain-layer.svg">` เบราว์เซอร์อาจไม่โหลดภาพภายนอกที่ SVG อ้างถึง ให้ใช้ตัวโหลดที่ให้มา หรือใช้รุ่นฝังภาพในตัวสำหรับ `<img>` เท่านั้น

ตัวอย่างกับชั้น SVG ที่เตรียมไว้ในแอป:

```js
import {loadMapLayers} from './map-art/load-map-layers.js';
const art = await loadMapLayers(artSlot, {
  assetBase: new URL('./map-art/', document.baseURI),
  includeWall: false, // แอปมี TK.wall อยู่แล้ว
  theme: 'night',
  prefix: 'story-map-v3-'
});
// art.terrain / art.water เป็น <g> แยก ย้ายไปยัง slot ของ renderer ได้
// เพื่อสอดสีเขตระหว่างพื้นดินกับน้ำ โดยไม่เปลี่ยนพิกัด
art.setTheme('day'); // หรือ night; ไม่เปลี่ยนชื่อ/สัญลักษณ์/ข้อมูลเรื่อง
```

กำหนด cache header สำหรับ PNG/SVG แบบไฟล์ static ตามวิธี deploy ของแอป เซิร์ฟเวอร์ห้องทดลองใช้ no-store เพื่อไม่ให้ตรวจภาพเก่าค้าง ไม่ใช่ค่าแนะนำของ production

## เมือง ชื่อ และไอคอน

ชุดฐานยังคง `containsCities:false`, `containsLabels:false`, `containsRoads:false` ไม่มีชื่อหรือรูปเมืองฝังในภาพ ใช้ `GLYPH` / `labeler` ของจริงต่อไป

ต้นแบบอัปเดตสำเนา places/roads/geo/timeline/wall แบบอ่านอย่างเดียวและเก็บ hash แล้ว การ์ดเมืองเพิ่ม `sdx/sdy/anchor`, `year/gone`, note และฉากที่อ้างหมุดโดยตรง รายการฉาก **ไม่นับ** ถนนหรือกล้องที่ผ่านจุดนั้นโดยอ้อม

โฟลเดอร์ `icons/` ที่อยู่ข้างโฟลเดอร์นี้เป็น **ข้อเสนอ 6 ชนิดสำหรับให้เจ้าของเลือก** ยังไม่ใช่คำสั่งให้แทน GLYPH และยังไม่ใช่ชุดครบทุก type คง anchor กลางของด่าน ความหมายสีตามชนิด และระบบ LOD เดิมไว้ ถ้าเลือกแบบสองระดับสี ต้องปรับเฉพาะการวาดไม่ให้ CSS เดิมทับ fill ของทุก path

## ความถูกต้องที่ยืนยันได้และขอบเขต

- น้ำเหนือฉางอาน–เป่ยหยวนและบริเวณขอบขวาเดิมต่อเป็นแนวครบแผ่น แยกแขนงเฉิงตู/เย่เฉิงและต่อแยงซีตะวันตกตามภาพแล้ว
- ตรวจโครงสร้างครบ 95 เส้น ปลายร่วมตรงกัน ไม่มีพิกัดผิด/NaN ไม่มีเส้นย้อนซ้ำจุดเดิม และปากน้ำ/จุดต่อกับรูปน้ำที่ตรวจ 14 จุดไม่มีช่องว่างตามความกว้างที่ใช้วาด
- ข้อมูลไม่ใช่กราฟไหลของน้ำหรือกราฟเดินเรือ: บางแขนงแตะกลางเส้น บางจุดเชื่อมผ่านพื้นที่ทะเลสาบ `from/to` ไม่ใช่ทิศกระแสน้ำ
- เส้นใต้ตัวหนังสือและทางเชื่อมที่ภาพเว้นว่างเป็นการตีความที่บันทึกไว้ ไม่ใช่การกู้พิกเซลที่ถูกบัง
- รูปหงเจ๋อขนาดใหญ่คงตามแผ่นที่โครงการใช้ ซึ่งไม่ตรงขอบน้ำยุคสามก๊ก อ่านหลักฐานในบันทึกภูมิศาสตร์ก่อนใช้เป็นข้ออ้างในเนื้อเรื่อง
- ภูเขามีครบทุกพื้นที่สัญลักษณ์เขียวที่กำหนดไว้ในแผ่น ไม่ได้หยุดที่กวานจง แต่ภาพต้นฉบับไม่ใช่แผนที่ภูมิประเทศละเอียดทั่วประเทศ ส่วนตะวันตกเฉิงตูที่เพิ่มมีเหตุผลภูมิศาสตร์ระดับภูมิภาค ขอบพิกเซลและรายสันเขายังเป็นงานศิลป์
