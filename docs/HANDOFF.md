> *"ทำไมเราถึงเอาขอบออกเฉย ๆ ไม่ได้ล่ะ แผนที่อันเก่ายังไม่มีเลย ซ่อนมันไว้ไม่ได้เหรอ ...
>  พอขอบมันเข้ม มันเหมือนการซอยเขตให้มันชัดโดยใช้ขอบเข้มเข้ามาตี ซึ่งไม่ต้องทำแบบนั้นก็ได้
>  เพราะเขตเราเอามาแบ่งดำเนินเรื่องเองด้วยซ้ำ · **แผนที่เก่าไม่มีปัญหา ทำไมอันนี้มีล่ะ**"*

**คำถามสุดท้ายชี้ตรงเข้าต้นเหตุ และคำตอบคือขอบไม่เคยจำเป็นเลยตั้งแต่แรก:**

1. **แผ่นเก่าไม่มีปัญหาเพราะใต้สีไม่มีอะไรให้กลบ** — หมึกภูเขาบน `map.jpg` มีแค่
   17,963 px = **0.56 % ของแผ่น** (วัดไว้ที่ LOG §5.12) ทาทับ `.45` ก็ไม่เสียอะไร
2. **แผ่นใหม่มีภาพนูนเต็มแผ่น รอบแรกจึงโดนกลบจริง** — ตารางใน HANDOFF เก่าที่ว่า
   `.45` แล้วภูเขาหาย เป็นตัวเลขจริง **ณ ตอนนั้น**
3. **แต่ปัญหานั้นถูกแก้ไปแล้วด้วยวิธีอื่น ตั้งแต่วันเดียวกัน** — `loadArt()` ยกภาพนูน
   ออกไปไว้ **เหนือ** สีเขต (`#L-relief` + `multiply`) ภูเขาจึงเลิกอยู่ใต้สี
   มันทำหน้าที่ *ทำให้มืดลง* จากข้างบน → **ความทึบของสีเขตเลิกเกี่ยวกับภูเขา**
   ผมวัด `.45` ไว้ *ก่อน* ทำ multiply แล้วไม่เคยกลับไปวัดใหม่ ขอบจึงค้างอยู่
   ในฐานะทางแก้ของปัญหาที่ตัวเองแก้ไปแล้ว
4. ★★ **และขอบนั้นผิด `DECISIONS §17` ข้อ 1 ที่ล็อกไว้ตั้งแต่ 2026-08-25 ตรง ๆ**
   *"ห้ามวาดพรมแดนภายในกลุ่ม และห้ามมีเส้นซ้อนสองชั้นบนพรมแดนร่วม"*
   — ขอบลากพรมแดนมณฑล **ภายในฝ่ายเดียวกัน** ครบทุกเส้น (คือ "เส้นซอย" ที่เจ้าของเห็น)
   และเพราะเขตข้างเคียงใช้ arc ร่วมกัน (§16) พรมแดนร่วมจึงถูก stroke **สองครั้ง**
