## การใช้ชื่อและหลักฐาน

แผ่นต้นแบบเรียกทั้งเมืองและศูนย์กลางกุ๋นด้วยชื่อเขต จึงใช้เป็นชื่ออ้างอิงบนแผนที่เรื่อง ไม่อ้างว่าทุกกุ๋นจัดตั้งในปี221 แล้ว โดยเฉพาะเจี้ยนหนิง (เดิมอี้โจวจวิ้น) ซิงกู่และเจี้ยนอานมีหมายเหตุในทะเบียน พิกัดเหล่านี้คือจุดบนแผ่นวาดมือ ไม่ใช่พิกัดภูมิศาสตร์ที่วัดสมัยใหม่

- [โฮ่วฮั่นซู เล่ม111](https://zh.wikisource.org/wiki/後漢書/卷111): เฉินหลิวและตงจวิ้นในเหยี่ยนโจว; เผิงเฉิงและเซี่ยพีในสวีโจว
- [จิ้นซู เล่ม15](https://zh.wikisource.org/wiki/晉書/卷015): หลูหลิงแยกจากยฺหวี่จางในหยางโจว และรายละเอียดหัวเมืองจิง–หยาง–เจียว ต้องอ่านช่วงเวลาก่อนนำชื่อมาใช้
- [สามก๊กจี่ เล่ม33](https://zh.wikisource.org/wiki/三國志/卷33): การเปลี่ยนชื่ออี้โจวจวิ้นเป็นเจี้ยนหนิงและแยกกุ๋นทางใต้

การตรวจ check_zhou ครอบคลุมหมุด 118 จุด (เดิม94 + ใหม่24) ผ่านครบตามบัญชีสังกัดที่ระบุ เป็นการตรวจความสอดคล้องของตำแหน่งกับเส้นบนแผ่น ไม่ใช่หลักฐานความแม่นระดับกิโลเมตร

## สิ่งที่ลง index หลักพร้อมกัน

- ภาพรวม/ปกซ่อนอี๋หลิงและโช่วชุน แม้ฉากจะบังคับหมุด; เจียงหลิงกับเหอเฝยยังอยู่
- เสบียงฮั่นจงซ่อนเฉพาะระดับภาพรวม กลับมาเมื่อซูมเข้า
- ภาพรวมเลือก23เมือง รวมหลินจือ เฉินหลิว เผิงเฉิง หนานไห่ และเจี้ยนหนิง ส่วนเมืองใหม่ที่เหลือเปิดเมื่อซูมภูมิภาค/ใกล้ ค้นหาและคลิกดูข้อมูลได้
- ย้ายตำแหน่งตัวอักษรจิงโจว/หยางโจวให้ห่างเจียงหลิงและกลุ่มเมืองริมแยงซี
- ปรับเส้นยง–อี้ท่อนตะวันตกเป็นแนวประมาณของที่สูงหมินซาน เก็บหมุดอู่ตู/อินผิงเหนือแนวและฮั่นจงใต้แนว
- ปรับเส้นจิง–หยางให้หลูหลิงอยู่ฝั่งหยาง ส่วนอี้–เจียวคงเมืองหนานจงเหนือแนวและยฺหวี่หลิน/เหอผู่ใต้แนว ปลายเส้นยังเป็นแนวประมาณ ไม่อ้างว่าเป็นขอบเขตสำรวจ
- ตัดการขยายสีฮั่นขึ้นบนชายขอบตะวันตกของหลงโย่ว/เหอซี 3198 ช่อง พื้นที่นั้นแสดงภูมิประเทศกลาง ไม่อ้างว่าเป็นเว่ยทั้งหมด
- คืนส่วนสีฮั่นที่ล้ำลงเจียวโจว3777ช่องให้เขต jiaozhou ซึ่งเริ่มด้วยหวูและเปลี่ยนมือได้ตาม engine ในภายหลัง
