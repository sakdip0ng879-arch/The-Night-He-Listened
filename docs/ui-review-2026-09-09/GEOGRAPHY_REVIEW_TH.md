# ตรวจเขตเริ่มเรื่องและภาพรวมแผนที่ — 10 กันยายน 2026

## สิ่งที่ลง index หลักแล้วในรอบนี้

- แก้ปกซูมแล้วคลิก/ปล่อยเมาส์กระโดดซ้าย: กล้องเต็มแผ่นมีค่า x ติดลบได้ แต่การคืนกล้องหลังปล่อยเมาส์ยังบังคับ x ≥ 0 อยู่ ตอนนี้ใช้ขอบเขตเดียวกับกล้องซูม
- แก้ลิ่มสีขาดมุมซ้ายล่าง: ตารางพื้นที่มีเจ้าของครบตรงนั้นอยู่แล้ว แต่ Chaikin ตัดมุมกรอบ (0,1950) ออก การสร้างขอบที่ติดกรอบจึงต้องเก็บมุมฉาก ไม่ทำ smoothing ข้ามมุม
- สร้าง geo_fill ใหม่ เปลี่ยนเฉพาะ arc ชนกรอบ 3 เส้นของ yizhou, liaodong, yangzhou พรมแดนภายในทุกเส้นเหมือนก่อนแก้ ไม่มีการเปลี่ยนเจ้าของเริ่มต้นหรือ mapDelta
- ภาพรวมเดสก์ท็อปแสดงชื่อมณฑลครบ 14 ชื่อ จองพื้นที่โดยหลบไอคอนก่อนให้ชื่อเมืองเลือกตำแหน่ง มณฑลแคบใช้ชื่อ 14px ที่เหลือ 17px ขยับชื่อโดยไม่ให้แนวการขยับตัดข้ามเส้นมณฑล
- เพิ่มเมืองภาพรวมเป็น 20 จุดที่มีทะเบียนและพิกัดอยู่แล้ว: ราชธานี 7 จุด + ฮั่นจง ไป๋ตี้เฉิง เทียนสุ่ย อู่เวย เฉินชาง จิ้นหยาง ฟ่านหยาง หว่าน เซียงหยาง เจียงหลิง โช่วชุน เหอเฝย กว่างหลิง
- ซ่อนไอคอนเสบียงซ้อนฮั่นจงใน UI ใหม่ เก็บไอคอนเมืองและข้อมูลระบบไว้

ชื่อเมืองยังใช้ระบบหลบชน: เมืองบางแห่งในกลุ่มหนาแน่นอาจเหลือไอคอนตอนเต็มแผ่นและเห็นชื่อเมื่อซูม/ชี้ ไม่ได้อ้างว่าทั้ง 20 ชื่อปรากฏพร้อมกันทุกขนาดจอ ส่วนระดับซูมภูมิภาคและใกล้ยังแสดงรายละเอียดตามเดิม

## ประเมินประวัติศาสตร์ก่อนเปลี่ยนพื้นที่

**ยังไม่ควรใช้เส้นมณฑลปัจจุบันเป็นแม่พิมพ์ทาสีฝ่ายทั้งมณฑล** เขตการปกครองกับอำนาจควบคุมเป็นคนละข้อมูล และเส้นของโครงการเป็นเส้นประมาณบนแผ่นวาดมือ ไม่ใช่เส้นที่สอบเทียบจากแผนที่ประวัติศาสตร์ฉบับหนึ่ง

1. **ฮั่นเริ่มเรื่อง:** แกนหลักคืออี้โจวรวมฮั่นจง ไม่ควรมีแนวสีครอบครองยื่นเข้าหลงโย่ว/เหอซีตั้งแต่ต้น ข้อมูลเจ้าของตอนนี้ให้ฮั่นเพียง yizhou และ hanzhong อยู่แล้ว ปัญหาอยู่ที่รูป yizhou ขยายขึ้นตามช่องว่างฝั่งตะวันตกของเส้นแดงต้นแบบ จนเกิดแถบเขียวเหนือขอบอี้โจว ไม่ใช่การตั้ง wudu เป็นฮั่นเร็วเกินไป
2. **อู่ตู–อินผิง:** พงศาวดารบันทึกการได้สองกุ๋นใน ค.ศ.229 แต่เรื่องของเราเปลี่ยนประวัติศาสตร์และได้อู่ตูใน c2-03 ปี221 ต้องรักษาลำดับของเรื่อง หลังแก้รูปควรเห็นการขยายเหนืออย่างชัดเจนในฉากนี้ ไม่ย้ายปีฉากให้ตรงประวัติศาสตร์จริง [สามก๊กจี่ เล่ม35](https://zh.wikisource.org/wiki/三國志/卷35)
3. **อี้โจวทางใต้:** เจี้ยนหนิงเป็นส่วนของอี้โจวในยุคจ๊ก ส่วนหนิงโจวที่แยกภายหลัง และเหลียงโจว 梁州 ที่ฮั่นจง เป็นการจัดเขตยุคจิ้น จึงไม่ควรยกชื่อและเส้นของยุคหลังกลับมาเป็นเขตเริ่มปี221 [จิ้นซู ภูมิศาสตร์ บนเว็บไซต์มหาวิทยาลัยนาโกยา](https://toyoshi.lit.nagoya-u.ac.jp/maruha/siryo/jinshu014-015.html)
4. **หวูกับเจียวโจว:** ใช้สีหวูในภาพรวมปี221 ได้ในความหมายการสวามิภักดิ์ ซื่อเซี่ยและน้องยอมรับอำนาจซุนเฉวียนเมื่อปู้จื้อเข้ามาในปี210 แต่ฐานอำนาจท้องถิ่นยังคงอยู่ ก่อนความขัดแย้งและการปราบในปี226 จึงไม่ควรบรรยายว่าเป็นการควบคุมโดยตรงอย่างสม่ำเสมอทั้งหมด [สามก๊กจี่ ชีวประวัติซื่อเซี่ย](https://www.xuoda.com/ls/sgz/222.htm)
5. **เจียวโจวทั้งมณฑล ≠ พื้นที่ใต้เส้นประปัจจุบันทั้งหมดโดยอัตโนมัติ:** เส้น yi–jiao ในโครงการระบุเองว่าหยาบที่สุด ยังไม่มีเมืองหลักทางใต้ให้ตรวจฝั่งครบ ขณะเดียวกันต้นแบบมีข้อความ Jiao Zhou / Jian Ning อยู่กลุ่มเดียวกัน จึงต้องตรวจที่ตั้งและสังกัดก่อนเปลี่ยนแถบเขียวใต้เส้นนั้นเป็นสีหวูทั้งหมด
6. **ยง–เหลียง:** การแยกเหอซีออกเป็นเหลียงมีฐานในเอกสาร แต่รายละเอียดสังกัดและช่วงตั้ง/ยุบเขตเปลี่ยนตามยุค จิ้นซูส่วนยงโจวเองกล่าวถึงหลายช่วงต่อเนื่อง ไม่ใช่หลักฐานเส้นพิกัดปี221 ทีละจุด จึงยังรับรองเส้นบนแผ่นทั้งหมดว่าแม่นตรงประวัติศาสตร์ไม่ได้ [จิ้นซู เล่ม14 ส่วนยงโจว](https://zh.wikisource.org/wiki/晉書/卷014#雍州)

ต้นแบบใช้เป็นหลักพิกัดและภูมิประเทศต่อไปได้ แต่มีชื่อหลายยุค เช่น Qin Zhou, Liang Zhou ที่ฮั่นจง และ Guang Zhou จึงต้องแยกการลอกตำแหน่งออกจากการรับรองปีของเขตปกครอง

## ข้อเสนอแก้สีรอบถัดไปอย่างเป็นขั้นตอน

1. ทำแนวควบคุมเริ่มปี221 แยกจากแนวมณฑล คงแกนเฉิงตู–ฮั่นจง–ไป๋ตี้เฉิงและหนานจง ไม่เพิ่มพื้นที่ฮั่นไปหลงโย่ว/เหอซี
2. ตรวจแนวตะวันตกเหนือเสฉวนด้วยเมืองอ้างอิง: อินผิง อู่ตู ตี๋เต้า หลงซี เทียนสุ่ย และจินเฉิง กำหนดขอบเขตของแต่ละเขตที่เรื่องยึดเป็นลำดับ ก่อนสร้างรูปใหม่
3. พื้นที่ที่เอาออกจากฮั่น **ไม่ควรกลายเป็นเว่ยทั้งหมดทันที**: แยกแนวเมือง/หุบเขาที่เว่ยควบคุมออกจากชายขอบที่ราบสูงซึ่งหลักฐานการควบคุมไม่แน่น ห้ามทาสีเพียงเพื่อให้ไม่มีพื้นที่ว่าง
4. ตรวจแถบใต้ด้วยเจี้ยนหนิง/หนานจงเทียบกับยฺหวี่หลิน–เหอผู่–เจียวจื่อก่อนแก้ yi–jiao เส้นนี้ยังต้องการหลักฐานตำแหน่งบนต้นแบบเพิ่ม
5. แก้ที่ข้อมูลสร้างรูปและสร้าง shared arcs ใหม่ ไม่แปะสีทับลงภาพพื้น และไม่เพิ่มยอดประชากร/ทหารตามพื้นที่พิกเซล

**ส่วนนี้เป็นข้อเสนอที่ยังไม่ได้ลงสีจริง** การแก้บั๊กมุมกรอบข้างต้นเป็นอีกเรื่องหนึ่ง ไม่ใช่การรับรองเขตการเมืองเดิมว่าถูกต้องแล้ว

ฉากที่ต้องตรวจเทียบก่อน–หลังจากข้อมูลฉากจริง:

| ฉาก | ปี | เขตเปลี่ยนเป็นฮั่น |
|---|---:|---|
| c2-03 | 221 | wudu |
| c2-06 | 222 | longxi |
| c2-07 | 222 | tianshui, anding |
| c3-04 | 223 | jincheng |
| c3-08 | 224 | wuwei, zhangye |

ต้องทดสอบการเปลี่ยนมือย้อนกลับภายหลัง โดยเฉพาะเทียนสุ่ยด้วย ห้ามอาศัยปีจากคอมเมนต์สรุปเก่าแทนข้อมูลฉาก

## เมืองนอกทะเบียนและความรก

ไม่ต้องลงทุกเมืองก่อนแก้ปกหรือการซูม รายชื่อที่เจ้าของเสนอเป็นแกนภาพรวมที่ดี แต่ยงโจวกับจิงโจวเหนือจะหนาแน่นมาก ควรคงเมืองสำคัญเหล่านี้ แล้วเพิ่มเพียงตัวแทนมณฑลที่ยังโล้น แทนเพิ่มจำนวนเท่ากันทุกมณฑล

- รอบนี้ใช้จิ้นหยางแทนปิงโจว ฟ่านหยางแทนโยวโจว และกว่างหลิงเป็นจุดที่มีอยู่แล้วในสวีโจว
- ชิงโจวและเหยี่ยนโจวยังไม่มีเมืองตัวแทนในทะเบียนปัจจุบัน ควรตรวจหลินจือและเฉินหลิว/ผูหยางจากต้นแบบและเอกสารก่อนเพิ่ม ส่วนสวีโจวอาจใช้เผิงเฉิงเป็นตัวแทนได้เหมาะกว่ากว่างหลิงเมื่อสอบเทียบแล้ว
- เมืองใต้ที่ต้องใช้ตรวจเส้นเขตมีความสำคัญกว่าการลงเมืองรองทั้งหมดในครั้งเดียว
- คงชื่อมณฑลครบในภาพรวม แล้วซ่อนชื่อมณฑลเมื่อซูมเข้า แสดงเมืองรอง ด่าน ภูเขาตามลำดับ แผนที่อ้างอิงใส่ชื่อทุกแห่งได้เพราะชื่อย่อตามภาพ แต่ UI ที่รักษาขนาดชื่อให้อ่านได้ควรคัดตามระดับซูม

## หลักฐานการตรวจรอบนี้

- Chrome จริง: `studio-geography3` — ชื่อมณฑล 14, ไอคอนเมืองภาพรวม 20, ปกซูมแล้วปล่อยเมาส์คงตำแหน่ง, ซูมใกล้ซ่อนชื่อมณฑล
- สี Canvas ตรงข้อมูลทั้ง 132 ฉาก รวมการรอการเดินทัพจบก่อนเปลี่ยนสี และสลับกลับแผ่นต้นฉบับได้
- selfcheck เดสก์ท็อป 132 ฉาก: errors 0 / warnings 0; ไม่ได้หมายความว่าป้ายบนมือถือทุกฉากผ่านการตรวจสายตาครบแล้ว
- `check_geo_edges.js`: ขอบ 12 ท่อนอยู่บนกรอบจริง ไม่ตัดเป็นลิ่ม
- `check_map.js` และ `check_zhou.js` ผ่าน มีคำเตือนเดิมเรื่องกองทัพถอยและจุดป้ายริมเส้น ข้อหลังตรวจความสอดคล้องของข้อมูล 94 จุด ไม่ใช่การพิสูจน์ความแม่นของเส้นตามประวัติศาสตร์
- ยังไม่ได้เพิ่มเมืองใหม่ที่ต้องสอบเทียบ หรือเปลี่ยนแนวการเมืองเหนือ/ใต้ตามข้อเสนอ
