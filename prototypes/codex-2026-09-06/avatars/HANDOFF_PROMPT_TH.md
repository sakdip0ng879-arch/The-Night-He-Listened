# พรอมป์ต์ส่งต่องาน Avatar — สไตล์ที่เจ้าของเลือกแล้ว

ใช้ข้อความด้านล่างกับโมเดลสร้างภาพ พร้อมแนบ `approved/liubei.png` และ `../shared/names.js` หากโมเดลนั้นเข้าถึงไฟล์ในเครื่องนี้ไม่ได้

---

ช่วยสร้างชุดภาพตัวละครสามก๊กสำหรับเรื่องประวัติศาสตร์ทางเลือก โดยใช้ **ภาพหลิวเป้ยที่แนบเป็นสไตล์ที่อนุมัติแล้ว** และใช้รายชื่อจาก `names.js` เท่านั้น

## ข้อมูลและลำดับ

- อ่าน `id` เป็นชื่อไฟล์, `label` เป็นชื่อไทย, `py` เป็นชื่ออังกฤษ, `side` เป็นฝ่าย
- ตรวจจำนวนก่อนทำ: ไฟล์ชุดนี้มี 80 ตัวละคร เริ่ม liubei แล้ว guanyu ห้ามเพิ่ม ข้าม หรือทำชื่อซ้ำ
- `note` อาจเป็นเรื่องสมมติ ใช้เข้าใจบทบาทเท่านั้น ห้ามอ้างว่าเป็นประวัติศาสตร์จริง
- หลิวเป้ยมีภาพตัวอย่างแล้ว งานแรกคือเตรียมภาพนั้นให้มีพื้นโปร่งใสและระยะขอบที่เหมาะสม หลังจากนั้นเริ่มตัวที่ 2 คือ guanyu ตามลำดับในไฟล์
- หากอ่านภาพหรือรายชื่อไม่ได้ ให้บอกและขอไฟล์ ห้ามเดารายชื่อ

## สไตล์ที่เลือก

- ภาพวาดตัวละคร 2D กึ่งสมจริงแบบเกมกลยุทธ์ประวัติศาสตร์ พู่กันละเอียด แสงนุ่ม สีหม่นและวัสดุมีน้ำหนัก
- สัดส่วนผู้ใหญ่ ใบหน้ามีวัย บุคลิก และประสบการณ์ตามตัวละคร ไม่เป็น chibi หรือ pixel art
- ไม่ใช่ภาพถ่าย ภาพ 3D คนหน้ามันเงา หรือเกราะแฟนตาซีเกินจริง
- ใช้ภาพหลิวเป้ยเป็นหลักเรื่องฝีแปรง การลงสี แสง รายละเอียด และสัดส่วน แต่ห้ามทำทุกคนหน้าเหมือนหลิวเป้ย
- แต่ละคนมีโครงหน้า ทรงผม หนวดเครา เสื้อผ้า และของประจำตัวที่แยกแยะได้ ฝ่ายเป็นข้อมูลช่วยจัดชุดสี ไม่บังคับให้ทุกคนใส่เครื่องแบบเหมือนกัน

## องค์ประกอบที่ต้องรักษา

- หนึ่งภาพมีหนึ่งคน หน้าตรงทั้งใบหน้าและลำตัว ยืนเต็มตัวตั้งแต่ยอดหมวกถึงเท้า
- ไม่ทำมุมสามส่วน ด้านข้าง ด้านหลัง sprite sheet หรือหลายท่าในภาพเดียว
- ตัวละครอยู่กลางผืนภาพสี่เหลี่ยมจัตุรัส มีระยะขอบปลอดภัยรอบหมวก เท้า อาวุธ และชายเสื้อ ให้ความสูงรวมใกล้เคียงกันทั้งชุด ประมาณ 82–86% ของผืนภาพ
- **ส่งออก PNG ที่มี alpha โปร่งใสจริง** ไม่มีพื้นขาว ไม่มีพื้นลายตารางปลอม ไม่มีฉาก ภูมิประเทศ วงพื้นใต้เท้า หรือเงาทอดออกนอกตัวละคร
- เก็บเงาและแสงบนร่างกาย/เสื้อผ้าได้ ขอบผมและอาวุธต้องสะอาด ไม่มีขอบขาวติดมา
- ไม่มีข้อความ ชื่อ ป้าย กรอบ watermark หรือ UI ในภาพ
- เว็บจะเป็นผู้ครอปใบหน้าและวางกรอบ/สีพื้นเอง จึงไม่ต้องวาดกรอบหรือฉากหลังไว้ในไฟล์

## ขั้นแรก: หลิวเป้ย

เตรียมภาพหลิวเป้ยที่แนบให้พื้นโปร่งใสจริง รักษาใบหน้า อายุ สีหน้า เสื้อผ้าเขียว–ครีม–ทอง ดาบคู่ และฝีแปรงเดิม เปลี่ยนเฉพาะพื้นหลังและระยะขอบ ห้ามออกแบบตัวละครใหม่ แสดงผลให้ตรวจว่าขอบไม่มีพื้นขาวตกค้างก่อนใช้เป็น master ของชุด

## ขั้นต่อไป: อีก 79 คน

ใช้ภาพ master หลิวเป้ยร่วมกับสไตล์ต้นฉบับเป็น reference แล้วทำตาม `names.js` ทีละคน ตั้งชื่อ `id.png` เช่น `guanyu.png`, `kongming.png`

สร้างภาพจริงด้วยเครื่องมือสร้างภาพ แยกหนึ่งไฟล์ต่อหนึ่งตัวละคร ไม่ส่งเพียงคำบรรยาย/พรอมป์ต์ หากมีข้อจำกัดจำนวน ให้แบ่งชุด บันทึกว่าทำถึง id ใด ตัวต่อไปคือใคร และแสดงสถานะแต่ละคน ห้ามข้ามหรือทำซ้ำ

บันทึก manifest ที่มี order, id, label, py, side, status, file เพื่อส่งต่อได้เมื่อหยุดงาน ตรวจไฟล์ alpha และขนาดภาพจริงก่อนรายงานว่าเสร็จ
