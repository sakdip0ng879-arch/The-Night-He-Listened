# Environment 01 — งานศิลป์ทั้งแผ่น ส่งให้ Claude ใช้กับ Engine เดิม

8 กันยายน 2026 · เจ้าของอนุมัติสไตล์ป่าใน study-01 และให้ Codex ดูแลงานศิลป์ต่อทั้งแผ่น

## ผลลัพธ์และขอบเขต

สร้าง Environment ครอบคลุมพิกัด 0 0 1650 1950 มีผิวดิน หญ้า พุ่ม และป่าเรือนยอดเป็นกลุ่ม วางร่วมกับภูเขาและน้ำชุด 04 ได้แล้ว **ป่าไม่แบ่งตามฝ่ายหรือมณฑล และไม่เปลี่ยนเมื่อมณฑลเปลี่ยนมือ** ไม่มีเมือง ตัวหนังสือ น้ำ ถนน หรือสีฝ่ายฝังอยู่ใน PNG

ภูมิภาคเหนือ/ตะวันตกเฉียงเหนือใช้ดินอุ่นและพืชโปร่ง กลางแผ่นมีป่าสลับพื้นที่เปิด เสฉวนเว้นที่ราบรอบเฉิงตู ภาคใต้มีป่าเป็นกลุ่มหนาแน่นกว่า ทิศทางนี้เป็นการตีความศิลป์ตามบริบทภูมิประเทศ ไม่ใช่การอ้างแผนที่ป่าในปีใดปีหนึ่ง

คงงาน art ownership ไว้ฝั่ง Codex: Claude รวม assets และเชื่อม state ของ Engine หากมีจุดงานศิลป์ไม่ลงตัว ให้ระบุพิกัด/ภาพมาเพื่อแก้ asset แยกรุ่น ไม่ต้องสร้างภาพป่าใหม่หรือระบายพื้นทับเอง

## ไฟล์ที่นำไปใช้จริง — 3 ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| environment-art.png | ภาพ Environment ทั้งแผ่น ไม่มีข้อมูลการเมือง |
| environment-layer.svg | ภาพ + ตัวปรับโทน + mask เว้นน้ำ ภูเขา ถนน และจุดเมือง |
| environment-layer.js | ตัวติดตั้ง classic script ซึ่งฝังข้อความ SVG ไว้แล้ว ใช้ได้ทั้ง HTTP และ file://; อ้าง PNG แยก |

ownership-palette.json เป็นค่าสีและความเข้มที่เสนอ ส่วน preview.js, preview-data.js, index.html, preview-base และ preview-icons ใช้ตรวจงานเท่านั้น **ห้ามย้าย logic ผู้ครองจำลอง/ฐานเมืองของหน้า preview ไปทับ Engine** ข้อมูลเมืองใน preview เป็น snapshot 107 จุดจากเวลาสร้าง ไม่ได้บอกว่าฐานข้อมูลในงานจริงต้องมีเท่านี้

PNG ที่เครื่องมือส่งจริงคือ **1153×1364** แม้ขอ 3300×3900 ใช้เป็นภาพบรรยากาศที่ขนาดแผนที่ปกติ เมื่อซูมลึกจะเห็นความนุ่มของเรือนยอด ยังไม่ใช่ชุด tiles รายละเอียดสูง ไฟล์เดิมไม่ได้ upscale เพื่ออ้างความละเอียดเพิ่ม

## การติดตั้งในชั้นแผนที่

นำสามไฟล์ไปไว้ใน assets/map-art/environment/ หรือโฟลเดอร์ศิลป์ที่เหมาะสม ไม่ต้องแก้ signature ของ load-map-layers.js รุ่น 04

ลำดับที่แนะนำ: พื้นกระดาษ/ภูเขาเดิม → Environment → สีครองพื้นที่บาง ๆ → น้ำ → กำแพง/ถนน → หมุด/ป้าย → แสงเน้นเหตุการณ์

Environment มี mask ทำให้ยอดภูเขาเดิมยังเห็นอยู่ ทับพื้นที่น้ำด้วย shape เดิมจึงไม่เกิดป่ากลางทะเลสาบ ใช้ group ภายใต้ [data-art-layer="environment"] เสมอเพื่อป้องกันกฎ fill:none ของ Engine ไปปิด mask

```html
<script src="assets/map-art/environment/environment-layer.js"></script>
```

ตัวอย่างเมื่อมี reference ของชั้นน้ำแล้ว (ปรับเฉพาะตัวแปร DOM ให้ตรงกับ Engine):

```js
const environment = TKEnvironment.mount(waterLayer.parentNode, {
  before: waterLayer,
  assetBase: new URL('./assets/map-art/environment/', document.baseURI),
  opacity: 0.82,
  theme: 'day'
});
// เรียกจากสวิตช์โหมดของ Engine เดิม
environment.setTheme('night'); // หรือ 'day'
environment.setOpacity(0.82);
// เมื่อล้างแผนที่ ให้เรียก environment.remove() ป้องกันการซ้อนซ้ำ
```

ตัวติดตั้งเติม prefix ให้ id ของ mask/filter และแก้ href ของ PNG ไม่ดัก pointer ไม่สร้าง event handler ของเกม ไม่อ่าน/เขียนเจ้าของมณฑล ไม่มี fetch ของ SVG จึงไม่ต้องแก้ tools/build_map_inline.js เพื่อฝัง Environment อีกครั้ง เพียงเพิ่ม classic script กับ PNG ให้เส้นทางถูก หากเลือก inline environment-layer.svg ด้วยตัวเอง ให้รักษา prefix และ relative image href ด้วย

เมื่อวางจริง อย่าให้ฟิลเตอร์กลางคืนของ parent ซ้ำกับ environment.setTheme ให้คำนวณเพียงครั้งเดียว ตัวอย่างนี้ parent ของชั้นศิลป์ไม่มี filter รวม ฟิลเตอร์อยู่ในแต่ละชั้น

## สีที่แนะนำ

ใช้สีฝ่ายเป็นข้อมูลทับฉาก ความอิ่มสีต่ำ และไม่ใช้เป็นสีต้นไม้:

| ฝ่าย | สีหลัก | รูปตราช่วยแยกฝ่าย |
|---|---|---|
| ฮั่น | #4F735E เขียวหยกหม่น | ◆ |
| วุย | #526A86 ครามเทาหม่น | ■ |
| ง่อ | #A46C50 ดินเผาหม่น | ▲ |
| ไม่ระบุ | #857C6B น้ำตาลเทา | ○ |

ค่าที่ตรวจใน preview: โหมดขอบเขตใช้ fill-opacity .045, โหมดลงสีใช้ .17 เส้นชายแดนต่างฝ่าย width 1.8 px opacity .85 เส้นแบ่งมณฑลฝ่ายเดียวกัน .6 px opacity .26 ใช้ vector-effect="non-scaling-stroke" ให้ความหนาคงที่ตอนซูม สีพื้นต้องอยู่บน Environment แต่ใต้น้ำ เมือง และชื่อ อย่าใส่ opacity ให้ parent ที่ครอบทั้งภาพ เพราะจะทำให้งานศิลป์ซีดตาม

**แนะนำโหมดขอบเขต + ตรามณฑลเป็นค่าปกติ** และให้โหมดสีพื้นเป็นปุ่มตรวจการเมือง เมื่อซูมกว้างเกินกว่าจะอ่านชื่อ ให้แสดงเฉพาะชื่อหลักพร้อม legend; เมื่อเลือกมณฑลค่อยเน้นสี .22 และแสดงชื่อ/ผู้ครองในแผงข้อมูลเสมอ อย่าใช้สีอย่างเดียว ตรารูปทรงและชื่อฝ่ายช่วยแยกฮั่นกับง่อเมื่อสีมองคล้ายกัน

ใน Engine สามารถเพิ่มแถบสี/ตราฝ่ายขนาดเล็กข้างหมุดเมืองจาก state เดิมได้ คงวัสดุอาคารเป็นกลาง ถ้าข้อมูลเจ้าของเมืองต่างจากเจ้าของมณฑล ให้ใช้ข้อมูลระดับเมืองที่ Engine มี ไม่อนุมานเจ้าของทุกเมืองจากการเติมสีมณฑล

## วิธีแสดงการได้มาซึ่งพื้นที่

หน้า preview มีตัวอย่างทำงานจริง: เลือกมณฑล → เลือกฝ่ายใหม่ → กด “ลองเปลี่ยนผู้ครอง” สีพื้น เส้นชายแดน และตรามณฑลเปลี่ยน พร้อมชั้นเน้นพื้นที่ค่อย ๆ จางใน 1.8 วินาทีและข้อความ ฝ่ายเดิม → ฝ่ายใหม่ ป่าและข้อมูลน้ำไม่เปลี่ยน

ในงานจริงให้รับ trigger จาก mapDelta ของ timeline เดิม:

1. ปรับ owner จาก state ที่ Engine ยืนยัน ห้ามให้ animation เขียนเนื้อเรื่องหรือเปลี่ยนข้อมูลต้นทาง
2. เน้นขอบเขตและเติมสีใหม่ชั่วครู่ แล้วจางกลับค่าปกติภายในประมาณ 1.8 วินาที แสดงข้อความชื่อพื้นที่และฝ่ายใหม่
3. เมืองศูนย์กลางเปลี่ยนตราฝ่ายตามข้อมูลจริง ความคืบหน้าที่ได้เพียงเมืองเดียวไม่ควรทำให้ทั้งมณฑลเปลี่ยนสี
4. หากเป็นพื้นที่ช่วงชิง แสดงเส้นประ/ลายเฉพาะพื้นที่ที่ Engine ระบุ ห้ามสร้างเขตคุมกำลังขึ้นจากรูปป่า
5. เปลี่ยนฉาก/ย้อนฉากเร็วต้องยกเลิก effect ที่ค้างและใช้ state ปัจจุบัน ไม่เล่นคิวเหตุการณ์เก่าทับกัน
6. prefers-reduced-motion: เปลี่ยน state และข้อความทันที ไม่มีการกระพริบหรือเคลื่อนกล้องอัตโนมัติ

ไม่ได้เพิ่มกฎรบ ระบบคลิก หรือฐานข้อมูลเมืองใหม่ให้ Engine งานตัวอย่างนี้มีไว้แสดงจังหวะภาพเท่านั้น

## เมื่อข้อมูลแผนที่เปลี่ยน

mask รอบนี้ใช้ geometry น้ำจาก delivery/water.json ชุด 04 และจุดเมือง/ถนนที่อ่านจาก data/places.js กับ data/roads.js ณ เวลาสร้าง ดู hash ใน manifest.json หาก Claude แก้น้ำหรือเพิ่มเมืองภายหลัง ให้แจ้ง Codex เพื่อสร้าง mask ใหม่ หรือปรับ mask จาก geometry ที่ยืนยันแล้ว โดย **ห้ามสร้าง mask ป่าจาก regions/owner**

แม้ preview ใช้ data/geo_fill.js วาดเส้นการเมือง แต่ environment-layer.svg ไม่ใช้ region polygon ใด ๆ ป่าจึงไม่ขาดตรงชายแดน ไม่จำเป็นต้องเปลี่ยนไฟล์ PNG เมื่อดินแดนเปลี่ยนมือ

## หลักฐานภูมิประเทศที่ใช้ประกอบทิศทาง

- [UNESCO เฉียงไหล–เจียจิน](https://whc.unesco.org/en/list/1213/) เป็นบริบทป่าและภูเขาทางตะวันตกของเฉิงตู ไม่ใช่แนวป่าโบราณในพิกัดแผ่นนี้
- [UNESCO South China Karst](https://whc.unesco.org/en/list/1248/) อธิบายภูมิประเทศเขตร้อนชื้นถึงกึ่งร้อนและพืชพรรณของเขตอนุรักษ์ ใช้ประกอบบรรยากาศภาคใต้ ไม่ได้คัดลอกขอบเขตป่าปัจจุบัน
- [งานวิจัยการกระจายพืชบนที่ราบสูงดินเหลือง](https://www.sciencedirect.com/science/article/pii/S0277379117300215) แยกป่าบนภูเขาออกจากทุ่งหญ้าบนพื้นที่ราบสูง สนับสนุนการไม่วาดป่าทึบทั่วภาคเหนือ แต่ไม่รับรองความหนาแน่นที่ศิลปินวาด

## ตรวจรับก่อนรวมจริง

ทดสอบ HTTP และ file:// ของงานจริง, โหมดวัน/คืน, ซูมใกล้/ไกล, ปิด Environment แล้วฐานเดิมยังอยู่, ป่าข้ามเส้นฝ่ายอย่างต่อเนื่อง, ไม่มีป่าในน้ำ, หมุดและข้อความอยู่บนสุด, เปลี่ยนฝ่าย/ย้อนฉากแล้วภูมิประเทศไม่เปลี่ยน และไม่ติดตั้ง group ซ้ำ ต้องใช้สีและ labeler จาก state ปัจจุบันของ Engine ไม่ใช้ snapshot จากหน้า preview
