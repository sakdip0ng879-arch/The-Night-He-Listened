# Environment ตัวอย่าง 01 — รอเลือกสไตล์

ตัวอย่างเฉิงตู/เสฉวน ตามภาพสีมณฑลที่เจ้าของส่ง 8 กันยายน 2026 ใช้ built-in ImageGen ไม่ใช้ CLI/API ไม่มีการแก้ production หรือชุดส่งมอบ v04

## ทิศทาง

ป่าเรือนยอดเป็นกลุ่มตามเชิงเขา ต่อเข้าสู่พุ่มและหญ้าบนที่ราบ ผิวดินสีหม่น ไม่ใช้ต้นไม้การ์ตูนซ้ำเป็นตาราง เว้นเมืองและเส้นน้ำให้โปร่ง รักษาสีมณฑลเป็นพื้นหลัก รอบนี้จำกัดบริเวณสีเขียวเพื่อเทียบกับบริเวณที่ยังไม่เติม

ภาพ chengdu-environment-concept.png เป็นภาพคอนเซปต์ที่สร้างจาก screenshot ทั้งใบ เครื่องมือเปลี่ยนตัวหนังสือ ไอคอน และรายละเอียดภูเขาบางส่วน จึงใช้เลือกบรรยากาศ/ความหนาแน่นเท่านั้น **ไม่ใช่ไฟล์ชั้น Environment ที่ Claude ควรนำไปวางทับแผนที่จริง** หน้าเทียบปรับขนาดภาพทั้งคู่ให้ตรงกรอบ จึงไม่ได้ใช้รับรองพิกัดหรือแม่น้ำ

## หลังสไตล์ลงตัว

1. สร้างเฉพาะวัสดุพื้นดิน/ป่าเป็น asset แยก ไม่มีเมือง ชื่อ ภูเขา หรือแม่น้ำติดมากับภาพ
2. วางบนพิกัดแผ่น 1650×1950 ใช้ขอบเขตภูมิประเทศและพื้นที่เว้นสำหรับน้ำ/ถนน/หมุดจากข้อมูลจริง ต้นไม้ข้ามเส้นแบ่งมณฑลได้ตามภูมิประเทศ ไม่หยุดที่ขอบสีเหมือนตัวอย่างทดลอง
3. ทดสอบร่วมสีมณฑลเขียว ฟ้า และส้ม พร้อมโหมดมืด สีป่าควรเป็นกลางกว่าในคอนเซปต์หากทำให้สีฝ่ายเปลี่ยน
4. ตรวจป้ายและสัญลักษณ์ของ Claude อยู่ด้านบนเสมอ ปรับความเข้มได้ และตรวจปากหุบเขายังเปิดอ่านเส้นทางได้
5. ขยายทีละภูมิภาคหลังตรวจบริบทภูมิศาสตร์ ไม่อ้างตำแหน่งป่าในคอนเซปต์เป็นข้อเท็จจริงประวัติศาสตร์
6. จัดทำ MD ส่งต่อ Claude ฉบับรวมจริงเมื่อผ่านสไตล์และตรวจทั้งแผ่นแล้ว
