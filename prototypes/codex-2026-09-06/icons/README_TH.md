# ไอคอนแบบเสนอ

ตัวอย่าง 7 ชนิด ใช้รูปทรงเดิมของ Claude เป็นจุดเปรียบเทียบ ไม่แก้ production

ไฟล์เดี่ยวเป็น SVG โปร่งใส viewBox 0 0 24 24 ส่วน symbols.svg เป็น symbol sprite ใช้ได้ผ่าน <use> หรือย้าย path เข้า renderer

แนะนำ 24–32 px; ที่เล็กกว่า 20 px ควรใช้ silhouette ของชุดเดิม ลดรายละเอียด ไม่ขยาย symbol ตามซูมแผนที่

คง sdx/sdy/anchor, ปีเริ่ม/สิ้นสุด, ชนิดสถานที่, การวางป้ายและความหมายสีเดิมทั้งหมด สีฝ่ายอยู่ที่ชั้นเจ้าของพื้นที่/เหตุการณ์ ไม่อยู่ที่รูปสถานที่

ห้ามนำ SVG นี้ไปใส่ใน GLYPH ตรง ๆ แล้วใช้ CSS ที่ override fill ทุก path เพราะจะเสียเงาสองระดับ ให้ปรับเฉพาะตัววาดหลังเจ้าของเลือกแบบ
