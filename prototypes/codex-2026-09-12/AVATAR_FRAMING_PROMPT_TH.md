# พรอมป์ต์ส่งต่อ: เตรียมภาพ Avatar ให้เข้ากรอบ UI โดยศีรษะไม่ถูกตัด

> อัปเดต 2026-09-13: จัดกรอบครบทั้ง 80 ตัวเรียบร้อยแล้วใน `map-portraits/` พร้อม PNG 128/256 และหน้าตรวจเทียบ อ่าน [วิธีใช้ชุดภาพ](map-portraits/README_TH.md) ก่อน ข้อความด้านล่างเป็นพรอมป์ต์เก่าสำหรับการปรับภาพในอนาคต ไม่ต้องให้ session อื่นทำกรอบทั้งชุดซ้ำ

ปัญหาที่พบในต้นแบบ: ภาพหลิวเป้ยมีศีรษะ/มงกุฎครบอยู่ในไฟล์ แต่หน้าเว็บขยายภาพ 1.55 เท่าและเลื่อนขึ้น ทำให้มงกุฎกับหน้าผากถูกตัด ตอนนี้แก้หน้าเว็บเป็น `object-fit: contain` ไม่ขยายหรือเลื่อนภาพแล้ว จึงไม่ต้องสร้างหลิวเป้ยใหม่เพื่อแก้ข้อผิดพลาดนี้

อย่างไรก็ตาม ภาพแต่ละตัวมีสัดส่วนหน้าไม่เท่ากัน บางรูปมีอาวุธหรือพื้นที่ว่างมาก ทำให้หน้าดูเล็กเมื่อใช้เป็นหมุด 36–48 px ถ้าจะเตรียมชุดสำหรับหมุดให้ชัดขึ้น ส่งข้อความด้านล่างให้ session งานภาพได้เลย

---

ช่วยเตรียม **ชุดภาพใบหน้าสำหรับ UI** จากภาพตัวละครที่มีอยู่ โดยรักษาหน้าตา สไตล์ สี และรายละเอียดเดิม ไม่สร้างตัวละครใหม่และไม่เขียนทับชุด `ready` ที่ส่งมอบแล้ว

อ่านรายชื่อจาก `data/names.js` ปัจจุบัน และตรวจเทียบ id กับ `prototypes/codex-2026-09-06/avatars/ready/manifest.json` ก่อนทำ ใช้ id เป็นชื่อไฟล์ จำนวนคาดว่า 80 ตัว ต้องตรวจจริงและรายงานไฟล์ที่ขาด ห้ามเดาชื่อหรือใช้รูปของอีกตัวแทน

เป้าหมายคือภาพช่วงศีรษะถึงไหล่/อกบนสำหรับหมุด ไม่ใช่ภาพเต็มตัวที่ย่อให้เล็กทั้งภาพ โดยมีเงื่อนไขดังนี้:

1. ต้องเห็นยอดผม หมวก มงกุฎ หรือเครื่องประดับบนศีรษะครบ รวมทั้งหน้าผาก หู ใบหน้า และคาง ไม่ตัดยอดมงกุฎเพื่อขยายใบหน้า
2. เริ่มจากการจัดกรอบ/ครอปต้นฉบับที่มีอยู่ ไม่จำเป็นต้องสร้างภาพใหม่ ถ้าต้นฉบับขาดส่วนศีรษะจริง ให้รายงานและเสนอแก้เฉพาะตัวนั้นก่อน
3. สร้าง PNG โปร่งใสขนาด 256×256 และ 128×128 พิกเซล ไม่มีพื้นขาว ไม่มีวงหรือกรอบฝังในภาพ UI จะใส่พื้นงาช้างและสีฝ่ายเอง
4. จัดใบหน้าให้อยู่กึ่งกลาง ใช้บริเวณศีรษะรวมเครื่องประดับเป็นเกณฑ์ ไม่ใช้กรอบ alpha ทั้งตัวหรือปลายอาวุธเป็นเกณฑ์ เพราะจะทำให้หน้าของคนถืออาวุธเล็กกว่าคนอื่น
5. เว้นพื้นที่เหนือยอดศีรษะ/เครื่องประดับประมาณ 8–12% และเผื่อด้านข้างให้พอ เครื่องประดับกว้างต้องลดสเกลหรือใช้กรอบทรงมนที่รองรับ ห้ามตัดทิ้ง
6. เน้นขนาดใบหน้าที่ใกล้กัน แต่ยอมให้ใบหน้าเล็กลงได้เมื่อหมวกหรือมงกุฎสูง ห้ามบิดสัดส่วนเพื่อบังคับให้ทุกหน้าใหญ่เท่ากัน
7. ภาพหมุดตัดอาวุธที่อยู่นอกกรอบใบหน้าออกได้ เก็บอาวุธและภาพเต็มตัวในไฟล์เดิมสำหรับการ์ดใหญ่ ห้ามตัดอาวุธแล้วเติมมือหรือร่างกายที่ผิดไปจากต้นฉบับ
8. ตรวจภาพจริงในกรอบวงกลมและกรอบสี่เหลี่ยมมุมมนที่ขนาด 32, 40, 48 และ 96 px โดยเว็บใช้ภาพเต็มกรอบ (`contain`) ไม่มี CSS ขยาย 1.4/1.55 เท่าหรือเลื่อนขึ้นอีก ตรวจว่าขอบวงกลมไม่ตัดส่วนสำคัญของมงกุฎ
9. ถ้ารูปใดไม่สามารถอยู่ในกรอบวงกลมโดยรักษารายละเอียดครบ ให้เสนอใช้กรอบสี่เหลี่ยมมุมมนกับตัวนั้น/ทั้งชุด ไม่ตัดศีรษะเพื่อให้ผ่าน
10. เริ่มด้วยหลิวเป้ย (`liubei`), จ้าวหยุน (`zhaoyun`), หม่าไต้ (`madai`), เฉาเจิน (`caozhen`) และกัวหวย (`guohuai`) ซึ่งใช้ในต้นแบบท้องพระโรงและศึกเทียนสุ่ย ให้เจ้าของตรวจชุดนี้ก่อนทำครบ

ส่งออกในโฟลเดอร์ใหม่ เช่น `avatars/ui-portraits-candidate/128/` และ `256/` พร้อมภาพเปรียบเทียบกรอบจริง และ manifest ระบุ id, sourceFile, outputFile, crop rectangle, ระยะเหนือเครื่องประดับ, กรอบที่ผ่านตรวจ และตัวที่ยังต้องแก้ ไม่แก้ HTML/CSS หรือข้อมูลฉากเอง

ข้อย้ำ: ภาพขนาดเล็กต้องจำหน้าได้ แต่ **การเห็นศีรษะและเครื่องประดับครบมาก่อนการขยายหน้าให้ใหญ่**
