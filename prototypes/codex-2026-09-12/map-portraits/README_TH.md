# ชุดอวตารสำหรับหมุดแผนที่ — 13 กันยายน 2026

> สถานะล่าสุด: ผู้ใช้อนุมัติให้นำเข้าหน้า index หลักแล้ว ชุดงานจริงอยู่ `assets/avatars/map/` อ่าน README ที่นั่นสำหรับการใช้ใน engine โฟลเดอร์นี้เก็บต้นแบบและเครื่องมือจัดกรอบไว้

จัดกรอบภาพเดิมครบ **80 ตัวตาม data/names.js** ไม่มีการเพิ่มตัวละครหรือสร้างใบหน้าใหม่ ส่งออก PNG โปร่งใส 128×128 และ 256×256 รวม 160 ไฟล์ ชื่อตาม id ตรวจภาพทั้งชุดในกรอบกลมแล้ว ภาพเต็มตัวและภาพการ์ดจากชุด ready ยังคงเดิม

เปิด `http://localhost:8778/prototypes/codex-2026-09-12/map-portraits/index.html` เพื่อเทียบก่อน/หลัง แบ่ง 20 ตัวต่อหน้า ค้นชื่อไทยหรือ id ได้ และมีปุ่มดูห้าตัวที่ใช้ในต้นแบบ ลองขนาด 32/40/48 px และเปิดเส้นอ้างอิงดวงตาได้

## วิธีจัดกรอบ

- กำหนดกึ่งกลางดวงตาและยอดศีรษะรายคนใน `frames.json` ไม่ใช้ขอบอาวุธหรือกรอบเต็มตัวเป็นจุดกึ่งกลาง
- กึ่งกลางดวงตาอยู่ x=50%, y=49% โดยประมาณจากการตรวจด้วยสายตา เว้นพื้นที่เหนือหมวก 7–14% ของภาพสี่เหลี่ยม
- `kebineng` ใช้ y=42% เพราะผ้าคาดหัวเตี้ยและเครายาว ต้องเผื่อคางด้านล่าง
- ผู้ที่มีพู่หมวกสูง เช่น `caozhen`, `machao` มีใบหน้าเล็กกว่าบางคนเพื่อเก็บเครื่องประดับครบ ไม่บังคับขนาดหน้าจนตัดหมวก
- ใช้ภาพเต็มตัว 1254 px เป็นแหล่งครอป ยกเว้น `caozhen` ใช้ภาพ 192 px ที่ชุดเดิมเก็บขอบภาพไว้สะอาดแล้ว ภาพ 256 ของตัวนี้เป็นการขยาย ไม่ได้มีรายละเอียดเพิ่ม เหมาะกับหมุดขนาดเล็ก
- PNG ไม่มีพื้นสีหรือวงกลมฝังไว้ สีพื้นและขอบเป็นหน้าที่ของ UI ภาพช่วงไหล่/อกถูกตัดตามกรอบได้

## นำไปใช้

ต้นแบบ `prototype.js` และ `war.js` ใช้ชุดนี้กับวงกลมขนาดเล็กแล้ว การ์ดใหญ่ยังใช้ชุดภาพการ์ดเดิม ตำแหน่งหมุดและเส้นทางเดินทัพคงเดิม **ยังไม่รวมอวตารเข้า engine/index หลัก**

โหลด `128/{id}.png` สำหรับหมุด 32–48 px หรือ `256/{id}.png` เมื่อแสดงใหญ่ขึ้น ใช้ `object-fit:contain` และไม่เพิ่ม CSS zoom/เลื่อนขึ้นอีก เพราะเฟรมจูนในไฟล์ภาพแล้ว

`manifest.json` ระบุแหล่งภาพ กรอบต้นฉบับ และ SHA256 ของไฟล์ทั้งหมด `build.cjs` สร้างภาพซ้ำจาก `frames.json` ผ่านหน้า export บน localhost:8778 ส่วน `complete-frames.cjs` เป็นบันทึกเริ่มต้นของค่ารายคน ไม่ต้องรันซ้ำหลังจูนค่าใหม่

ตรวจข้อมูลด้วย `node prototypes/codex-2026-09-12/map-portraits/verify.cjs` และตรวจหน้าเว็บด้วย `node prototypes/codex-2026-09-12/audit.cjs` ภาพรวมวงกลมทั้งชุดอยู่ใน `final-page-0.png` ถึง `final-page-3.png`
