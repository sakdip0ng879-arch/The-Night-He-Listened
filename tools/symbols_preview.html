ตารางสัญลักษณ์สถานที่ — ✅ ล็อกแล้ว 2026-09-02 (DECISIONS §3)

แก้ตามที่เคาะ: ค่าย = กระโจมโค้งใบเดียว + รั้วเด่น · ค่ายนา = กระท่อม + ร่องนา · และแยกภูเขาออกจากตารางสัญลักษณ์ ไปเป็นชั้นภูมิประเทศ

1 · สิบเอ็ดสัญลักษณ์จุด (ภูเขาย้ายออกแล้ว — ดูหัวข้อ 4)

คอลัมน์ ฉาก = ขนาดที่เห็นจริงตอนกล้องซูมฉาก (~17px) · ทั้งแผ่น = ตอนถอยออกดูทั้งแผ่นดิน (~9px)

ออกแบบ 48pxฉากทั้งแผ่นชนิดในข้อมูลคนอ่านควรอ๋อว่า

2 · แถบจำลองบริบทจริง

สีเขต + กราฟถนน + สัญลักษณ์ + ลูกศรเดินทัพของฉากทับข้างบน — ทุกชั้นซ้อนกันแบบบนจอจริง

3 · ★ ภูเขา — คุณทักถูก ผมแก้ตารางตัวเอง

สามแผงข้างล่างใช้ ข้อมูลสันเขาชุดเดียวกันเป๊ะ (24 สัน จำลองความหนาแน่นแถบฉินหลิ่ง–ฉีซาน) มีถนนสองสายลอดหุบเหมือนกันทั้งสามแผง ต่างกันแค่วิธีวาด · ขนาดคือสเกลจริงตอนซูมฉาก

ก · ทึบล้วน (ที่ผมเสนอรอบแรก)

ตก — ซ้อนกันแล้วเป็นก้อนดำก้อนเดียว ไม่รู้ว่ามีกี่สัน หุบอยู่ไหน ถนนหายเข้าไปในก้อน

ข · เส้นโปร่งล้วน (แบบที่แผ่นเดิมใช้)

ตกเหมือนกัน แต่คนละอาการ — เส้นของสันที่อยู่*ข้างหลัง*ทะลุออกมาหมด กลายเป็นตาข่าย ไม่ใช่ภูเขา

ค · เงาข้างเดียว แต่ยังไม่บังกัน

มีมิติขึ้นมาก แต่ยังเห็นเส้นของสันหลังทะลุสันหน้าอยู่

★ ง · เงาข้างเดียว + บังกัน — สันหน้าบังสันหลัง

อันนี้แหละ — เติมสีกระดาษทึบในตัวสันก่อนลากเส้น สันที่อยู่หน้าจึงบังสันที่อยู่หลังเหมือนของจริง · ตาอ่านเป็น เทือก ทันที เห็นชั้นลึก เห็นหุบ และถนนยังเด่นอยู่

✅ เคาะครบแล้ว 2026-09-02
ชายคาโค้ง · ด่านคร่อมถนน · ค่ายนา = กระท่อม + ร่องนาเส้นตรงเฉียง · ค่าย = กระโจมโค้ง + รั้วหนา
ภูเขา: ภูมิประเทศใช้ เส้นสัน + ขีดลาด + เงาลาดขวา (ดู relief_test.html) · ภูเขาที่มีชื่อใช้สามเหลี่ยมทึบตามคอนเวนชันเดิมของแผ่น
